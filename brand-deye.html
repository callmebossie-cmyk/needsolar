Deye Hybrid Inverter อินเวอร์เตอร์ไฮบริดยืดหยุ่น

Hybrid Inverter ที่รองรับแบตเตอรี่ ไฟสำรอง AC coupling และ time-of-use settings เหมาะกับบ้านที่ต้องการความยืดหยุ่นในการออกแบบระบบ

Deye วางตำแหน่งตัวเองเป็น Flexible Hybrid Inverter ที่เน้นความยืดหยุ่นในการออกแบบระบบ ทั้งการทำงานร่วมกับแบตเตอรี่ การรองรับ on-grid/off-grid การ AC couple กับระบบโซลาร์เดิม และการตั้งค่าการชาร์จ/คายประจุแบตเตอรี่ตามช่วงเวลา ทำให้ Deye เหมาะกับตลาดไทยมาก โดยเฉพาะบ้านที่เริ่มจากระบบลดค่าไฟก่อน แล้วค่อยขยายเพิ่มแบตเตอรี่ภายหลัง

จุดแข็งที่ 1 — Hybrid Inverter ครบฟังก์ชันในตัวเดียว

HYBRID

Deye Hybrid Inverter เป็น multifunctional inverter ที่รวม inverter, solar charger และ battery charger ไว้ในกล่องเดียว ทำให้จ่ายไฟได้ต่อเนื่องในทุกสถานการณ์ ไม่ว่าจะเป็นไฟจากแผงโซลาร์ แบตเตอรี่ หรือการไฟฟ้า โดยระบบจะจัดการลำดับความสำคัญให้อัตโนมัติ

  • บริหารจ่ายไฟจากแผง แบตเตอรี่ และกริดได้ในกล่องเดียว
  • ตั้งค่าลำดับความสำคัญของแหล่งพลังงานได้ตามต้องการ
  • รองรับ unload backup สำหรับอุปกรณ์สำคัญในบ้านเมื่อไฟดับ

จุดแข็งที่ 2 — AC Coupling รองรับงาน Retrofit

RETROFIT

หนึ่งในข้อได้เปรียบที่ชัดเจนของ Deye คือการรองรับ AC coupling ซึ่งช่วยให้ติดตั้งร่วมกับระบบโซลาร์เดิมที่มีอยู่แล้วได้ โดยไม่ต้องรื้อหรือเปลี่ยนอินเวอร์เตอร์เดิมทั้งหมด นี่คือจุดขายสำคัญสำหรับลูกค้าที่มีระบบ on-grid อยู่แล้วและต้องการเพิ่มไฟสำรอง

  • AC couple กับระบบโซลาร์เดิมได้โดยไม่ต้องเปลี่ยนอินเวอร์เตอร์เดิม
  • ลดต้นทุนการอัปเกรดระบบเดิมให้มีแบตเตอรี่สำรองไฟ
  • เหมาะกับบ้านที่ต้องการเพิ่มไฟสำรองในงบประมาณที่ควบคุมได้

จุดแข็งที่ 3 — Time-of-use และ Unbalanced Output

FLEXIBILITY

Deye รองรับการตั้งค่า time-of-use ซึ่งช่วยให้กำหนดช่วงเวลาชาร์จ/คายประจุแบตเตอรี่ได้ตามต้องการ เช่น ชาร์จแบตจากกริดในช่วงค่าไฟถูก แล้วนำมาใช้ในช่วงค่าไฟแพง นอกจากนี้ยังรองรับ 100% unbalanced output ซึ่งสำคัญสำหรับบ้านที่มีโหลดไม่สมดุลระหว่างเฟส

  • Time-of-use settings ตั้งค่าชาร์จ/ใช้แบตตามช่วงเวลาค่าไฟ
  • Unbalanced output รองรับโหลดไม่เท่ากันระหว่าง 3 เฟส
  • บางรุ่นรองรับการ parallel หลายเครื่องสำหรับโหลดขนาดใหญ่

จุดแข็งที่ 4 — Deye Cloud มอนิเตอร์ผ่านมือถือ

MONITORING

Deye Cloud เป็นแพลตฟอร์มมอนิเตอร์ระบบผ่านคลาวด์ที่ช่วยให้ผู้ใช้และผู้ติดตั้งติดตามการผลิตไฟ สถานะแบตเตอรี่ และการใช้พลังงานได้ Real-time ผ่านแอปมือถือ รวมถึงรายงานย้อนหลังสำหรับการวิเคราะห์ประสิทธิภาพ

  • มอนิเตอร์การผลิตไฟ สถานะแบต และการใช้งานแบบ Real-time
  • รายงานพลังงานรายวัน รายเดือน สำหรับวิเคราะห์ ROI
  • ผู้ติดตั้งสามารถตรวจสอบและ remote troubleshoot ได้ผ่าน Deye Cloud

Deye Hybrid Inverter เหมาะกับใคร

Deye เป็นตัวเลือกที่ยอดเยี่ยมสำหรับผู้ที่ต้องการ ระบบ Hybrid ที่ยืดหยุ่น คุ้มค่า โดยเฉพาะบ้านที่ต้องการไฟสำรองเมื่อไฟดับ หรือต้องการอัปเกรดระบบโซลาร์เดิมให้มีแบตเตอรี่โดยไม่ต้องเริ่มใหม่ทั้งหมด

  • บ้านที่ต้องการไฟสำรองสำหรับอุปกรณ์สำคัญเมื่อไฟดับ
  • บ้านที่มีระบบ on-grid อยู่แล้วและต้องการเพิ่มแบตเตอรี่ภายหลัง
  • ธุรกิจขนาดเล็กที่ต้องการบริหารค่าไฟด้วย time-of-use settings
  • งาน retrofit ที่ต้องการควบคุมงบประมาณ

คำถามที่พบบ่อย

Inverter แบบ on-grid ทั่วไปจะหยุดทำงานเมื่อไฟดับ แต่ Deye Hybrid Inverter สามารถจ่ายไฟจากแบตเตอรี่ต่อเนื่องได้แม้ไฟดับ อีกทั้งยังบริหารการชาร์จ/คายประจุแบตตามช่วงเวลาค่าไฟได้ ทำให้ประหยัดได้มากกว่า
ได้ ด้วยความสามารถ AC coupling ของ Deye สามารถติดตั้งร่วมกับระบบโซลาร์เดิม (on-grid inverter เดิม) และเพิ่มแบตเตอรี่ได้โดยไม่ต้องรื้อระบบเดิมทั้งหมด ช่วยลดต้นทุนการอัปเกรดได้อย่างมาก
NEED SOLAR มีแพ็กเกจ Deye ตั้งแต่ 5 kW (1 เฟส) ถึง 20 kW (3 เฟส) รองรับทั้งบ้านพักอาศัยและอาคารพาณิชย์ขนาดเล็ก สามารถคำนวณขนาดที่เหมาะสมได้ที่หน้าคำนวณโซลาร์
